# <Repo Name>

Static site + serverless function exercising Appwrite features (Users, Databases,
Functions, Messaging, Storage) on the self-hosted Appwrite 1.9.x server.

## Layout

```
site/                  static HTML site (Appwrite Sites, framework "other")
  index.html           import map + markup
  app.js               Appwrite Web SDK (Account, TablesDB, Storage, Functions, Messaging)
  appwrite-sdk.mjs     vendored esbuild bundle (NOT loaded from esm.sh)
  styles.css
  config.js            endpoint + project + resource IDs (no secrets)
functions/<fn-id>/     serverless function (Appwrite Functions, runtime node-16.0)
  src/main.js          CommonJS, native https (no fetch in node 16)
  package.json
appwrite.config.json   CLI project binding (generated by `appwrite init project`)
```

## The function

Runtime **node-16.0** (CommonJS, `module.exports = async (context)`). Calls an
OpenAI-compatible `/v1/chat/completions` endpoint, stores the exchange in the
TablesDB table, drafts a messaging email.

Function variables: `OPENAI_API_BASE_URL`, `OPENAI_API_KEY` (secret),
`OPENAI_MODEL`. The per-execution Appwrite key arrives on the `x-appwrite-key`
header (not an env var).

## Deployment

Both deploy from GitHub via the Appwrite GitHub App (VCS). Push to `main`
auto-deploys. Site root = `/site`; function root = `/functions/<fn-id>`.

## Local dev

Serve `site/` with any static server. Edit `site/config.js` to point at your
Appwrite project. Run the function locally with `appwrite run function`.

Built with the `appwrite-deploy` skill.
